Lumenfall Arena is an original arena-survival roguelite for the desktop browser, drawn entirely with canvas paths and sounded entirely with synthesized WebAudio — no external assets at all. You are the last Star-Warden: survive five minutes of escalating moths, darters, brutes and spitters in a dark indigo arena, gather the lumen shards they drop, level up and choose between new weapons (Orbit Blades, Nova Pulse, Chain Spark) and passives, then face the Hollow King at the four-minute mark. Survive to dawn with the King defeated to win. Move with WASD or the arrow keys, dash with Space or Shift, pause with P — your weapons fire on their own, so the game is all positioning, timing and build choices.

## Run it

```sh
node main.ts && python3 -m http.server 8080 --directory out/game
# then open http://localhost:8080 in a desktop browser — or serve the game/ folder
# directly with any static file server and open its index.html
```
